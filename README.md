## `> snake_setup`

<details>
<summary>Click to expand — How to enable the contribution snake animation</summary>

1. In your `hassansaeed2007` profile repository, create the folder `.github/workflows/`
2. Create a file named `snake.yml` inside it with this content:

```yaml
name: Generate Snake Animation

on:
  schedule:
    - cron: "0 0 * * *"
  workflow_dispatch:

jobs:
  generate:
    runs-on: ubuntu-latest
    steps:
      - uses: Platane/snk@v3
        with:
          github_user_name: ${{ github.repository_owner }}
          outputs: |
            dist/github-snake.svg
            dist/github-snake-dark.svg?palette=github-dark
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}

      - uses: crazy-max/ghaction-github-pages@v3
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

3. Go to **Settings → Actions → General** in the repo and set Workflow permissions to **Read and write**.
4. Run the workflow manually once from the **Actions** tab.

The snake SVGs will appear in the `output` branch and auto-update daily.

</details>
